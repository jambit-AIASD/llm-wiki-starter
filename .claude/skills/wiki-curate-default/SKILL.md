# Wiki Curate — Default Domain

This skill configures the wiki for a **general-purpose document knowledge base**.
It provides the domain configuration that CLAUDE.md defers to the skill system.
Read it at the start of any curation session for a general-purpose wiki.

---

## Wiki Domain

General-purpose knowledge base. Sources may include articles, papers, books,
meeting notes, reference documents, and imported reference material of any kind.

---

## Entity Types

- **People** — authors, stakeholders, researchers, named individuals
- **Organizations** — companies, institutions, vendors, third-party services
- **Products** — tools, systems, software, services
- **Places** — locations relevant to the source material

---

## Concept Types

- **Ideas / Topics** — theories, subjects, domains of knowledge
- **Frameworks** — methodologies, patterns, models
- **Terms** — definitions, jargon, terminology
- **Techniques** — approaches, methods, processes

---

## Emphasis Rules

- Always link claims back to the source page where they were raised.
- Flag any commitment or deadline with `⚠️ Commitment:`.
- Flag security/compliance concerns with `⚠️ Risk:`.
- When the same claim appears in multiple sources, note the evolution.

---

## No Domain Extensions

This domain has no extensions to the standard INGEST, LINT, or source page
format defined in CLAUDE.md. Follow those workflows as written.
